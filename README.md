## 🚀 Quickstart

All scripts include automatic virtualenv switching (`.venv`), so you can run them directly with standard `python3` or through the virtualenv:

### 1. Run the Model Diagnostic Audit
Verifies layer weights, parameters, hardware acceleration, and benchmarks inference speed:
```bash
python3 check_model.py
```

### 2. Run the 5-Second Quick Test
Runs inference on `sample_images/pure_crack_01.jpg` and saves `quick_test_output.jpg`:
```bash
python3 quick_test.py
```

### 3. Launch the Interactive Web Dashboard with Live Camera
```bash
python3 web_app.py
```
Open **[http://localhost:5050](http://localhost:5050)** in your browser:
- Click **"Open Live Camera"** to start real-time crack inspection from your webcam!
- Choose between camera overlays, heatmaps, and side-by-side view modes.
- Toggle CLAHE contrast enhancement for uneven lighting.
- Freeze any frame to inspect details.
- Switch to **"Image & Batch Mode"** to drag-and-drop photos or use the Before/After split comparison slider.

### 4. Run Desktop Native Camera Inspector (No Browser Needed)
If you prefer a native desktop window with OpenCV:
```bash
python3 live_camera.py
```
- Real-time overlay directly on your screen.
- Hotkeys: `[SPACE]` to freeze, `[c]` for CLAHE contrast, `[m]` to cycle modes, `[s]` to save snapshot, `[q]` to quit.

## 💻 CLI Usage (`predict.py`)

Run batch inference on individual images or entire directories:

```bash
# Run on sample images using high-resolution tiled mode
python3 predict.py --input sample_images/ --mode tiled --threshold 0.50

# Run on a single photo
python3 predict.py --input /path/to/my_wall.jpg --output-dir my_results/

# Fast mode (resizes image to 448x448)
python3 predict.py --input sample_images/ --mode full
```

### Output Files Generated:
- `<filename>_comparison.jpg`: 3-panel composite: `[Original Photo] | [Probability Heatmap] | [Crack Overlay + HUD]`
- `<filename>_overlay.jpg`: High-res original photo with highlighted crack boundaries
- `<filename>_mask.png`: Binary 0/255 segmentation mask
- `batch_summary.json`: Machine-readable metrics (confidence, area %, pixel count)

## 🐍 Using the Model in Your Own Python Code

### Option A: Using the High-Level `CrackPredictor` API
```python
from predict import CrackPredictor

# Initialize predictor (auto-detects MPS / CUDA / CPU)
predictor = CrackPredictor("model_unet_vgg_16_best.pt")

# Run inference
result = predictor.predict("sample_images/pure_crack_01.jpg", mode="tiled", threshold=0.5)

print("Crack detected:", result["crack_detected"])
print(f"Affected surface: {result['crack_percentage']}%")
print(f"Peak confidence: {result['peak_probability'] * 100:.1f}%")
print(f"Inference latency: {result['inference_time_ms']} ms")

# Binary mask (numpy uint8 array, 0 or 255)
mask = result["binary_mask"]
```

### Option B: Direct Raw PyTorch Loading
```python
import torch
from PIL import Image
import numpy as np
from unet_model import load_unet16_model, get_default_device

device = get_default_device()
model, meta = load_unet16_model("model_unet_vgg_16_best.pt", device=device)

# Prepare 448x448 image tensor
img = Image.open("sample_images/pure_crack_01.jpg").convert("RGB").resize((448, 448))
arr = np.array(img).astype(np.float32) / 255.0
arr = (arr - np.array([0.485, 0.456, 0.406])) / np.array([0.229, 0.224, 0.225])
tensor = torch.from_numpy(arr).permute(2, 0, 1).unsqueeze(0).float().to(device)

with torch.no_grad():
    logits = model(tensor)
    probabilities = torch.sigmoid(logits)[0, 0].cpu().numpy()

# probabilities is a (448, 448) float array with values in [0.0, 1.0]
```

## 🔍 Inference Modes Explained

- **`tiled` (Recommended for High-Res Photos)**:
  Slides a 448x448 window across the image with 25% overlap, runs inference on each patch, and smooths overlapping probabilities. Prevents thin hairline cracks from being blurred or erased by downscaling.
- **`full` (Fastest)**:
  Resizes the entire image directly to 448x448 in a single forward pass, then resizes the mask back to original dimensions. Ideal for fast previews or video frames.
